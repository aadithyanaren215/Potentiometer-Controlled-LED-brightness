# Potentiometer-Controlled-LED-brightness
Arduino based LED brightness control using a potentiometer
This project demonstrates how the brightness of an LED can be controlled using a potentiometer and Arduino Uno.

When the potentiometer is rotated, the Arduino reads the changing voltage and adjusts the LED brightness using PWM. Therefore, the LED does not simply switch between ON and OFF. Its brightness gradually increases or decreases.
